VOIDBLOOM is a neon arena survival shooter that runs entirely in the browser — no build step, no network calls. Pilot a lone ship against escalating waves of geometric hunters: dash through bullets with i-frames, build a combo multiplier up to ×8, draft 1-of-3 upgrades between waves, and face the VOIDMOTHER boss every fifth wave. Fully synthesized WebAudio sound and music, seeded stages, title / pause / game-over flow, and a persistent best score.

Controls: WASD or arrow keys to move, mouse to aim, click or hold to fire, Shift / Space to dash, P to pause, M to mute.

## Run it

```sh
node main.ts
```

That builds the entry into /output (game + screenshots + dossier.json). To play the game directly instead:

```sh
node serve.ts
```

then open http://localhost:8080.
